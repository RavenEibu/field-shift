# Source Selection Decision — 2026-10-30

## Accepted for the first reproducible baseline

- NASA POWER meteorology for regional historical climate context.
- NASA SMAP L4 SPL4SMGP v8 for regional surface/root-zone soil moisture context.
- INTA Mapa Nacional de Cultivos for Argentina crop-history context.
- INTA SisINTA as the preferred measured soil source system when a suitable representative profile is available.
- FAO crop-water references for the initial crop knowledge schema.

## Accepted only as fallback

- ISRIC SoilGrids 250 m for modeled soil context when suitable measured/local evidence cannot be obtained.

## Deferred

- ECOSTRESS
- HLS
- GPM IMERG
- GRACE / GRACE-FO

Deferral does not reject these products. They require a concrete decision gap before integration.

## Superseded MVP preference

SMAP L3 SPL3SMP_E remains a valid evaluated NASA source, but SMAP L4 is preferred for the first MVP baseline because root-zone soil moisture provides greater decision value for water-stress context.
