# Roadmap

This roadmap favors a complete, explainable decision loop over broad but unfinished integration.

## Phase 0 — Foundation

Status: in progress / largely complete

- public repository baseline
- English as canonical language
- human-first / AI-optimized principles
- security and contribution policy
- canonical context layer
- NASA source registry
- governed learning lifecycle
- transparent decision contract

## Phase 1 — Core data validation

- execute a NASA POWER retrieval for a real test location
- execute SMAP search and retrieval for the same area and period
- define canonical observation records
- validate units, missing values, time alignment, and spatial scope
- create reproducible examples and tests

## Phase 2 — Agricultural context

- select a target geography for the MVP
- identify authoritative or suitable public soil data
- define the first crop catalog
- document crop characteristics needed by the decision model
- define initial candidate rotations
- validate terminology and assumptions with agronomic references or expert review

## Phase 3 — Core decision loop

- derive a small set of transparent indicators
- implement evidence-backed rules
- incorporate farmer priorities
- compare multiple rotations
- expose evidence, risks, benefits, trade-offs, uncertainty, and limitations
- build one end-to-end reproducible demonstration

## Phase 4 — MVP+

Only after the core loop works:

- evaluate ECOSTRESS evapotranspiration / stress evidence
- evaluate HLS field-scale vegetation evidence
- use GPM where it adds value beyond POWER
- use GRACE / GRACE-FO only for broad hydrologic context

## Phase 5 — Learning demonstration

- create at least one realistic learning candidate
- evaluate it in shadow mode
- show how evidence can support promotion or rejection
- demonstrate that active behavior remains unchanged until approval

The goal is to demonstrate governed learning, not autonomous uncontrolled self-modification.

## Phase 6 — NASA presentation

- farmer-centered problem story
- working decision-support demo
- source provenance
- explainable recommendation trace
- uncertainty and scientific limitations
- human-first / AI-optimized architecture
- future learning and extensibility
