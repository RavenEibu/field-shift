# Presentation

This directory is reserved for NASA Space Apps presentation assets and final storytelling material.

## Narrative rule

The public story should remain challenge-first:

1. Agricultural problem
2. Farmer decision
3. NASA and local evidence
4. Field Shift decision-support approach
5. Demonstration
6. Explainability, uncertainty, and limitations
7. Impact and future learning

The reusable framework is supporting architecture, not the protagonist.

## Evidence rule

Presentation claims should remain consistent with the repository's validated context and source registry.

Do not simplify scientific limitations in a way that changes their meaning.
